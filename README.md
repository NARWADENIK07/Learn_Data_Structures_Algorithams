## How to Use This Repository

1. Start with Phase 1 and solve the beginner logic exercises.
2. Understand complexity before moving into data structures.
3. Learn every data structure with operations, visuals, and complexity tables.
4. Practice algorithms by understanding patterns, not memorization.
5. Use interview prep material after strong fundamentals.

## Learning Principles

- Understand the why, not just the code.
- Practice tracing code step by step.
- Compare time and space complexity before choosing an approach.
- Use diagrams and examples to internalize patterns.
- Solve problems repeatedly until the pattern becomes natural.

## Suggested Study Order

1. Variables, operators, loops, arrays, strings
2. Function-based problem solving
3. Recursion and backtracking basics
4. Complexity analysis
5. Data structures from arrays to graphs
6. Searching and sorting
7. DP and greedy strategies
8. Advanced DS and competitive patterns
9. Interview simulations and review

This repository is meant to be a guided learning journey, not just a code dump. Every topic should be studied with examples, reasoning, and practice.
