## Core Concept

Different structures are useful for different tasks:

- Arrays are ideal for indexing and fixed-size storage.
- Linked lists are useful when insertion and deletion are frequent.
- Stacks support LIFO logic.
- Queues support FIFO logic.
- Trees support hierarchical data and search.
- Graphs model relationships and networks.

## Complexity Reference

- Array access: O(1)
- Search in unsorted array: O(n)
- Search in sorted array with binary search: O(log n)
- Stack push/pop: O(1)
- Queue enqueue/dequeue: O(1)
- BST search/insert/delete: average O(log n)
- Graph BFS/DFS: O(V + E)

## Goal

The goal is to understand not only how each structure works, but also when to choose it and what trade-offs it has.
